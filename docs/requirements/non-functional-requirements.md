# Non-functional requirements

| ID                     | Requirement                                                         | How it is met                                                                                            | Evidence                                          |
| ---------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| NFR-01 Security        | Server-side authorization on every loader, action, download and job | `requireUser/requireStaff`, `staffApplicationScope`, `authorize*Download`                                | Integration authorization tests                   |
| NFR-02 Privacy         | No personal data in URLs, titles, notifications previews or logs    | Generic page titles, reference-only e-mails, pino redaction                                              | Code review                                       |
| NFR-03 Integrity       | Submitted revisions, audit, history, reviews append-only            | DB triggers (migration `…_append_only_and_constraints`)                                                  | Integration immutability test                     |
| NFR-04 Availability    | Zero-downtime deploys with rollback                                 | Blue-green + Nginx                                                                                       | Local simulation: 156 requests, 0 failures        |
| NFR-05 Recoverability  | Backup and tested restore of DB and files                           | `infrastructure/scripts/backup.sh`, `restore.sh`                                                         | Restore test: identical counts and file checksums |
| NFR-06 Accessibility   | WCAG 2.2 AA target                                                  | Semantic HTML, labels, error summary, focus ring, native dialogs, text status badges, ≥7:1 colour tokens | Manual review; automated axe audit not yet run    |
| NFR-07 Performance     | Long conversions never block web requests                           | Background worker + outbox                                                                               | Architecture                                      |
| NFR-08 Maintainability | Modular monolith, strict TypeScript, typed services                 | `app/modules/*`                                                                                          | `tsc --noEmit`, ESLint in CI                      |
| NFR-09 Portability     | Runs from a clean clone with Docker only                            | `compose.yaml`                                                                                           | Verified locally (Windows + Docker Desktop)       |
| NFR-10 Observability   | Structured JSON logs, health endpoints, job logs                    | pino, `/healthz/live`, `/healthz/ready`, worker heartbeat                                                | Verified locally                                  |
