# Threat model (STRIDE summary)

Assets: candidate personal data and documents, recruitment decisions, staff accounts, audit trail.

| Threat                 | Example                                                  | Controls                                                                                                                                                                                      | Residual / to do                                                                    |
| ---------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Spoofing               | Credential stuffing, session theft                       | Argon2id, lockout (8 failures/15 min), Redis rate limits (IP + hashed account), HttpOnly/SameSite/Secure `__Host-` cookies, hashed session tokens, rotation on login, revoke on reset/disable | MFA for staff not implemented; recommend college SSO or TOTP                        |
| Tampering              | Editing a submitted application; changing stored files   | Append-only DB triggers, revision SHA-256, file SHA-256 verified on every read, write-once generated PDFs, CSRF (Origin + RR origin check + HMAC token)                                       | DB superuser can still bypass triggers → restrict and audit DB access operationally |
| Repudiation            | Disputed decision                                        | Status history with actor/reason, audit of decisions, downloads, views, exports, role grants                                                                                                  | Ship audit logs off-host (not implemented)                                          |
| Information disclosure | IDOR on applications/files; cross-department access      | Record-level scope in every query, uniform 404, private storage outside web root, generic download filenames, no PII in URLs/titles/notification text, log redaction, CSP                     | Backups contain PII → encrypt off-host                                              |
| Denial of service      | Large uploads, conversion bombs                          | Size limits (Nginx 12 MB, app MAX_UPLOAD_MB), converter timeout/concurrency/memory limits, queue-based processing, Nginx rate limits                                                          | Image decompression bombs: dimensions capped at 10 000 px                           |
| Elevation of privilege | Admin reading applications; candidate granted staff role | Least-privilege role matrix, admins have no data access, candidate accounts cannot hold staff roles, DB app role without DDL                                                                  | —                                                                                   |
| Malicious files        | Malware, polyglots, scripts                              | Magic-byte detection (file-type), PDF parse with pdf-lib, encrypted PDFs rejected, ClamAV INSTREAM, downloads with `Content-Disposition: attachment`, `nosniff`, sandbox CSP                  | ClamAV signature freshness depends on egress                                        |
| XSS                    | Stored script in answers                                 | React escaping, no `dangerouslySetInnerHTML`, nonce-based CSP without `unsafe-inline` scripts                                                                                                 | —                                                                                   |
| Injection              | SQL, CSV formula                                         | Prisma parameterised queries (raw SQL uses tagged templates), CSV export prefixes formula characters                                                                                          | —                                                                                   |
