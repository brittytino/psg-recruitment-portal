## For future maintainers

- Keep the copyright notice in [LICENSE](./LICENSE) in every copy or fork.
- If you make a substantial change, add your name under _Later contributors_ with a one-line summary.
- Keep the project's ground rules:
  - TypeScript / Node.js only (web, worker and scripts).
  - Every input is validated on the server (Zod / form definitions).
  - State changes are atomic and recorded in the audit log.
  - Candidate data stays private: no personal data in logs, URLs or e-mails.
  - Database migrations are additive only; never drop or rename columns with live data.
